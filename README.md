## 📖 Overview

Welcome to my **Backend Engineering** learning repository.

This project focuses on server-side development using **JavaScript (Node.js)** and **MongoDB** as the NoSQL database. It covers the complete backend lifecycle, from setting up a basic REST API to database modeling.

## 🚀 Getting Started

To run the code from any specific branch locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Thimothy25/Backend-Class.git](https://github.com/Thimothy25/Backend-Class.git)
    cd Backend-Class
    ```

2.  **Switch to the desired branch:**
    ```bash
    git checkout Exercise6  # Replace with the branch you want to open
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Configure Environment:**
    * Create a `.env` file if required by the exercise.
    * Add your MongoDB Connection String.

5.  **Run the Server:**
    ```bash
    npm start
    # or
    node app.js
    ```
